环境状态 决定这台机器此刻处于什么条件

这三个量是整台机器在某一刻的状态，不是某个器件参数。温度影响晶振、CCD 暗电流、 伺服增益；电源老化影响轨电压、增益余量、钳位基准。它们的效应方向由物理决定—— 所以时间线只驱动一个数（暖度），至于暖度会动哪些参数，由模型决定。

设备个体 同型号的不同机器

同一型号的两台机器不一样：CCD 有暗电流容差、镜头装配有偏心、伺服板有增益差异、磁头磨损取决于用过多久。 填一个序列号，这台机器就固定下来——同一个串号永远给出同一台机器，所以故障可复现、磁带可复查。 留空就是名义模型，与加入这个维度之前的渲染逐位相同。

关键帧时间线 一段录像的生命周期

一段录像不是一组常数，而是一台机器历史上的一段：开头是冷的、二十分钟后热了、中途被搬进潮的地方、断电重启过。 每个轨道是一个参数随时间的取值。曲线属于开始该段的那个点，因为它描述的是「怎么从这里走到下一个点」： linear 恒定速率、exp 逼近平衡（温度、伺服稳定）、hold 离散状态不变、smooth 仅在无物理速率可依据时使用。
